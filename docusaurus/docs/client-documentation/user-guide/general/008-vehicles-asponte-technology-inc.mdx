Explore, filter, and search government contract vehicles, obligations, and agency details from the Vehicles page accessed via **Market Intel → Vehicles**.

![Vehicles Page](/img/client/008-vehicles-asponte-technology-inc-screenshot.png)

## Search and Filter

Use the search bar and filter controls at the top of the page to narrow down contract vehicles.

1. Type a search term into the **Type Contract Title, Funding agency, Awarding agency** search box.
2. Select a matching operator such as **Contains** from the dropdown list.
3. Click **Apply** to execute your search query.
4. Click **Filter** to configure advanced clauses, saved filters, or suggestions.

## Vehicles Table Reference

The main panel displays contract vehicle records across several data columns.

| Column | Description |
| :--- | :--- |
| **Contract Key** | Shortened name or abbreviation of the vehicle. |
| **Total Obligation** | Total dollar obligation for the contract vehicle. |
| **Awarding Agency** | Government agency responsible for awarding the contract vehicle. |
| **Funding Agency** | Government agency providing funding for the contract vehicle. |
| **Ceiling Amount** | Maximum funding limit available for awards under this vehicle. |
| **Total Contracts** | Total count of associated contracts. |
| **Total Awards** | Total count of awards issued under the vehicle. |

## Data Export

Click the **Export** button in the upper right corner of the data grid to export records and generate reports based on your current view or filter criteria.
