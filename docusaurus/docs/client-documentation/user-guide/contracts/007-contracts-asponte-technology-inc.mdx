Explore and search through federal contract records, track obligations, and analyze recipient data via **Contracts**.

## Search and Filter Contracts

Use the search bar and filter options to narrow down the contracts list.

1. Navigate to **Contracts** from the main menu.
2. Click **Keyword** or use the search field to enter criteria such as **Type Vehicle, Contract, Recipient, Parent Recipient, Awarding Agency Name , Funding Agency Name, Contract Tile**.
3. Select an operator from the dropdown (such as **Contains**) and click **Apply** to execute your search.
4. Click **Filter** to build advanced queries using custom clauses or saved filters.

## Contract Data Table

The main data grid organizes contract information across several columns.

| Column | Description |
| :--- | :--- |
| **Vehicle** | Vehicle associated with the award. |
| **Contract #** | Unique identifier assigned to the contract. |
| **Contract Title** | Description or title of the contract. |
| **Total Obligation** | Total obligated funding committed under the contract. |
| **Recipient** | Entity or organization awarded the contract. |
| **Parent Recipient** | Parent organization associated with the contract. |

## Exporting Records

To export contract data for offline analysis:

1. Click the **Export** button located above the data table.
2. Configure your export range using the **Start** and **End** fields.
3. Confirm your selections to download the records.
