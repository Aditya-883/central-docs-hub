Manage user profiles, review account details, and configure seat assignments by navigating to **Administration** and selecting a specific user.

## User profile and account details

The user management view breaks down individual profile data, access levels, and billing metrics across dedicated cards.

| Section / Element | Description |
|-------------------|-------------|
| **User Header** | Displays the user's name, email address, status badges (**Active**), and permission roles (**GOVCON360 User**, **GOVCON360 Client Admin**). Click **Edit name** to update user details. |
| **Account details** | Shows first name, last name, non-editable email, assigned roles, sign-in method, two-factor authentication status, join date, and last sign-in timestamp. |
| **Seat and billing** | Outlines committed seats, active seat usage, contract terms, and billing status for the organization. |
| **Admin access** | Displays administrative privileges and provides options to **Grant admin access** or **Deactivate user**. |

Use **Go Back** in the top right corner to return to the main user directory.
