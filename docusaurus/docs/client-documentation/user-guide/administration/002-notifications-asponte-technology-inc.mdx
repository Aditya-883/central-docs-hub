View and manage system alerts and messages by accessing the **Notifications** page from the top navigation bar.

![Notifications](/img/client/002-notifications-asponte-technology-inc-screenshot.png)

## Notification views

The notifications panel is divided into two primary views to help you track your updates:

| Tab | Description |
| :--- | :--- |
| **All** | Displays every notification received by your account, regardless of read status. |
| **Unread** | Filters the list to show only new notifications that require your attention. |

When no alerts are present, the interface displays a message indicating that you are completely caught up.
