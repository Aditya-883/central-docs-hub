Explore, search, and export government agency profiles and organizational hierarchies under **Market Intel → Agencies**.

![Agencies](/img/client/010-agencies-asponte-technology-inc-screenshot.png)

## Search and Filter Agencies

Use the search bar and filter controls to narrow down the list of government agencies.

1. Click **Keyword** or use the search field to enter text like **Type Agency, Top Level Agency**.
2. Select a conditional operator such as **Contains**, **Starting**, **Ending**, or **Exact match** from the dropdown.
3. Click **Apply** to execute your search.
4. Use the **Filter** button to configure advanced clauses, manage saved filters, or apply suggested filters.

## Agency Records Table

The main data table displays comprehensive information across several sortable columns:

| Column | Description |
| :--- | :--- |
| **Agency** | Official name of the government agency or office. |
| **Acronym** | Shortened name or abbreviation of the agency. |
| **Agency Level** | Hierarchy level of the agency within the government structure. |
| **Parent Agency** | Parent government department or higher-level agency associated with this agency. |
| **CGAC** | Common Government Accounting Code identifier. |
| **Description** | Summary or primary focus of the agency. |
| **Location** | Physical address or headquarters location. |

## Data Management and Export

You can export agency records or modify view layouts using the top action buttons.

- Click **Export** to open the export configuration dialog, specify your record range (**Start** and **End**), and click **Export records**.
- Switch between layout views using options such as **List View**, **Card**, **Chart View**, or **Map View**.
