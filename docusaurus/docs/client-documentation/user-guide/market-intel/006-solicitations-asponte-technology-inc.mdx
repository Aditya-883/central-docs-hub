description: "Search, filter, and review government solicitations using market intelligence tools."

Access the Solicitations page via **Market Intel → Solicitations**.

![Solicitations](/img/client/006-solicitations-asponte-technology-inc-screenshot.png)

## Search and filter solicitations

Use the search bar and filter controls to narrow down government contracting opportunities:

1. Click **Keyword** or use the **Type Solicitation Title, Solicitation Number** search box to look up specific records.
2. Select a search operator such as **Contains** from the dropdown menu.
3. Click **Apply** to execute the search.
4. Click **Filter** to configure advanced criteria, add clauses, and save your custom filters.

## Solicitations table reference

The main data table displays active government opportunities across several columns:

| Column | Description |
| :--- | :--- |
| **Solicitation #** | Unique identifier assigned to the solicitation notice. |
| **Solicitation Title** | Descriptive title of the opportunity. |
| **Top Office/ Agency Name** | Government office or agency issuing the solicitation. |
| **Posted Date** | Date when the solicitation was published. |
| **Set Aside** | Socio-economic set-aside category for the requirement. |
| **Type** | Notice type, such as Solicitation, Combined Synopsis/Solicitation, or Sources Sought. |

## Exporting records

Click the **Export** button in the upper-right corner of the data grid to download solicitation records in your preferred format.
