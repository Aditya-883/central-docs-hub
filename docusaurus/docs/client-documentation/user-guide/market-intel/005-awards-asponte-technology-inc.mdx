Explore, filter, and analyze federal award records within the Market Intel module. Access this view by navigating to **Market Intel** → **Awards**.

![Awards Page](/img/client/005-awards-asponte-technology-inc-screenshot.png)

## Search and Filter Awards

Use the search bar and filter controls at the top of the awards table to narrow down records by specific criteria.

1. Type your search terms into the **Type Vehicle, Contract, Award Id, Awarding Office, Funding Office, Recipient** search field.
2. Select a matching operator from the dropdown menu (such as **Contains**).
3. Click **Apply** to execute the search.
4. Click **Filter** to open advanced filter options, add clauses, or save customized filter sets.

## Awards Table

The main data table displays all matching federal awards along with key financial and organizational metrics. 

| Column | Description |
| :--- | :--- |
| **Vehicle** | Vehicle associated with the award. |
| **Contract #** | Name or identifier of the awarded contract. |
| **Award ID** | Unique identifier assigned to the award record. Click an ID to view detailed record information. |
| **Total Obligation** | Total obligated funding amount committed under the award. |
| **Parent Recipient** | Parent organization of the award recipient. |
| **Recipient** | The primary entity receiving the award. |

## Exporting Records

To download award data for offline analysis, click **Export** in the top-right corner of the data grid to configure your export settings and format options.
