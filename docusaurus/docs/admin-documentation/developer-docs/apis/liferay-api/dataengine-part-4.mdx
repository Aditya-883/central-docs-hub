## Endpoints

### POST `/data-engine/v2.0/data-definitions/{dataDefinitionId}/data-records/export-batch`

[DataRecord] DataEngine.v2.0.postDataDefinitionDataRecordsPageExportBatch

#### Parameters

| Name | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `dataDefinitionId` | path | string | Yes | Identifier for the data definition |
| `dataListViewId` | query | string | No | Optional data list view identifier |
| `keywords` | query | string | No | Search keywords |
| `sort` | query | string | No | Sort criteria |
| `callbackURL` | query | string | No | Callback URL for asynchronous completion |
| `contentType` | query | string | No | Content type format for export |
| `fieldNames` | query | string | No | Specific field names to include |

#### Request Example

```json
{
  "callbackURL": "https://client.example.com/webhook",
  "contentType": "application/json"
}
```

#### Response Example

```json
{
  "status": "Accepted",
  "message": "Batch export initiated."
}
```
