## Endpoints

### GET `/change-tracking-rest/v1.0/ct-remotes`

Retrieve a paginated list of change tracking remotes.

| Parameter | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `page` | query | string | No | Page number for pagination |
| `pageSize` | query | string | No | Number of items per page |
| `search` | query | string | No | Search query string |
| `sort` | query | string | No | Sorting criteria |

```json
{
  "items": [
    {
      "id": "12345",
      "name": "Remote Server A"
    }
  ],
  "page": 1,
  "pageSize": 20,
  "totalCount": 1
}
```

---

### POST `/change-tracking-rest/v1.0/ct-remotes`

Create a new change tracking remote entity.

```json

  "name": "New Remote Server",
  "url": "https://remote.example.com"
}
```

### POST `/change-tracking-rest/v1.0/ct-remotes/export-batch`

Export a batch of change tracking remotes.

| Parameter | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `search` | query | string | No | Search filter |
| `sort` | query | string | No | Sort criteria |
| `callbackURL` | query | string | No | Optional webhook callback URL |
| `contentType` | query | string | No | Response content type |
| `fieldNames` | query | string | No | Specific fields to export |
