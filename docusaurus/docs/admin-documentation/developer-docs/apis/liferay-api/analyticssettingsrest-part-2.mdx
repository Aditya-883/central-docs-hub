### PATCH `/analytics-settings-rest/v1.0/fields/orders`

`[Field] AnalyticsSettingsRest.v1.0.patchFieldOrder`

| Parameter | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `body` | body | array | Yes | Array of order field configurations to update |

```json
[
  {
    "fieldName": "string",
    "enabled": true
  }
]
```

```json

  "status": "SUCCESS"
}
```

### GET `/analytics-settings-rest/v1.0/fields/people`

`[Field] AnalyticsSettingsRest.v1.0.getFieldsPeoplePage`

| Parameter | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `keyword` | query | string | No | Search keyword |
| `page` | query | string | No | Page number |
| `pageSize` | query | string | No | Number of items per page |
