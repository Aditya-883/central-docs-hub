## Endpoints

### GET `/api/award/v1/federal-account-balances`

Get federal account balances

### GET `/api/award/v1/by-generated-unique-award-id`

Get award detail by generated unique award id

### GET `/api/award/v1/by-contract-number-and-award-id`

Get award detail by contract number and award id

### GET `/api/award/v1/by-award-id`

Get award detail by PIID

### GET `/api/award/v1/award-transaction-history`

Get award transactions by contract number

### GET `/api/award/v1/award-amount`

Get federal account balances

### GET `/api/award/v1/agency-vendor-summary`

Get vendor-wise obligation summary for an agency (PG)

### GET `/api/award/v1/agency-summary`

Get agency summary for a recipient (PG)

### GET `/api/award/v1/agency-monthly-obligation`

Get monthly obligation (PG) by agency org key

### GET `/api/award/v1/agency-category-obligation`

Get category obligation (PG) by agency org key
