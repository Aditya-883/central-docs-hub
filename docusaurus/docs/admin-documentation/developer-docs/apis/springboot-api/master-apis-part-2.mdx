## Endpoints

### GET `/api/master/v1/award-id`

Retrieves the list of award IDs. Supports optional keyword-based searching using the specified search option (`EXACT`, `STARTS_WITH`, `ENDS_WITH`, or `CONTAINS`). If no keyword is provided, all award IDs are returned.

#### Parameters

| Name | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `keyword` | query | string | No | Search keyword for award IDs |
| `search_option` | query | string | No | Search strategy (`EXACT`, `STARTS_WITH`, `ENDS_WITH`, `CONTAINS`) |

#### Response

`ResponseEntity<Wrapper>`

```json
{
  "status": "success",
  "data": [
    {
      "awardId": "AWARD-2023-001",
      "description": "Sample Award Description"
    }
  ]
}
```

### GET `/api/master/v1/agencies`

Retrieves the list of agencies. With search option `CONTAINS`, `STARTS_WITH`, `PREFIX`, `FUZZY`, `PHRASE`, or `ALL`, the keyword is a typeahead search: the last word matches as a prefix, words may contain typos, the full agency name and acronym (e.g., DOD, NASA) also match, and results are ranked best first with departments ahead of sub-agencies. `EXACT`, `ENDS_WITH`, and other options keep their literal SQL meaning. The `page` (0-based) and `limit` parameters page the results; without a limit, up to 1000 rows are returned. If no keyword is provided, departments come first.

#### Parameters

| Name | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `keyword` | query | string | No | Search keyword for agency name or acronym |
| `search_option` | query | string | No | Search strategy (`CONTAINS`, `STARTS_WITH`, `PREFIX`, `FUZZY`, `PHRASE`, `ALL`, `EXACT`, `ENDS_WITH`) |
| `page` | query | integer(int32) | No | 0-based page index |
| `limit` | query | integer(int32) | No | Maximum number of rows to return (up to 1000) |

#### Response

`ResponseEntity<Wrapper>`

```json
{
  "status": "success",
  "data": [
    {
      "agencyId": "1",
      "name": "National Aeronautics and Space Administration",
      "acronym": "NASA",
      "type": "Department"
    }
  ]
}
```
