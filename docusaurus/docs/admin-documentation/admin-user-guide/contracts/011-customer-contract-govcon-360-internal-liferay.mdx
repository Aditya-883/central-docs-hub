Manage customer contracts and seat allocations from the Customer Contract management interface. Access this page by navigating through your account settings or contract modules.

![Customer Contract Page](/img/admin/011-customer-contract-govcon-360-internal-liferay-screenshot.png)

## Managing customer contracts

Use the main table to view existing agreements, check active or inactive status, and review billing intervals. You can filter the existing list using the **Search by recipient name** field.

## Add Customer Contract modal

Click the **Add Customer Contract** button to open the creation form and set up a new agreement.

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **Recipient Name** | Select | No | Choose the recipient organization from the dropdown list. |
| **Start Date** | Date | No | Select the contract start date. |
| **End Date** | Date | No | Select the contract expiration or end date. |
| **Committed Seats** | Number | No | Enter the total number of committed seats. |
| **Billing Frequency** | Select | No | Choose how often billing occurs (e.g., **Quarterly**). |
| **Free trial (customer does not pay invoices)** | Checkbox | No | Enable if the contract is under a free trial period. |
| **Committed Price / Seat / Quarter** | Number | No | Specify the committed pricing per seat. |
| **Extra Price / Seat / Quarter** | Number | No | Specify the extra pricing per seat. |
| **Prorated Price / Seat / Day** | Number | No | Specify the prorated pricing per seat and day. |

Click **Add Customer Contract** to save your changes, or click **Cancel** to discard them.
