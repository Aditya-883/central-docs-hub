Manage customer contracts and seats allocation by navigating to **Commerce → Customer Contract**.

![Customer Contract](/img/admin/010-customer-contract-govcon-360-internal-liferay-screenshot.png)

## Customer contracts list

The main panel displays all registered customer contracts and their details. 

| Column | Description |
| :--- | :--- |
| **Recipient Name** | The name of the recipient associated with the contract. |
| **Start Date** | The date the contract becomes active. |
| **End Date** | The date the contract expires. |
| **Committed Units / Seats** | The number of committed units or seats. |
| **Billing Frequency** | How often billing occurs (e.g., **Quarterly**). |
| **Committed Amount** | The cost per billing period. |
| **Extra Price / Unit** | Additional pricing per unit. |
| **Prorated Price** | Prorated pricing details. |
| **Free Trial** | Indicates whether the contract includes a free trial (**No** or **Yes**). |
| **Status** | The current status of the contract (e.g., **Active** or **Inactive**). |

## Managing contracts

1. Use the **Search by recipient name** field to filter the contract list.
2. Click **Add Customer Contract** to create a new agreement.
3. Use the action icons on each row to view or edit existing contracts.
