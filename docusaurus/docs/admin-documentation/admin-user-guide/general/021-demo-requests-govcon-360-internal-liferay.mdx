Manage inbound prospect scheduling through the **Administration** module. Access this form by navigating to **Administration** and selecting the demo request form view.

![Demo Requests Page](/img/admin/021-demo-requests-govcon-360-internal-liferay-screenshot.png)

## General Information

Use the **General** section to capture contact details, professional titles, and scheduling preferences for prospective leads.

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **First Name** | Text | No | Prospect's given name. |
| **Last Name** | Text | No | Prospect's family name. |
| **Company Name** | Text | No | Organization or company represented. |
| **Email Address** | Text | No | Primary contact email. |
| **Phone Number** | Text | No | Primary contact phone number. |
| **Job Title** | Text | No | Prospect's professional title. |
| **Demo Date** | Text / Date Picker | No | Scheduled date and time for the product demonstration. |
| **Message** | Textarea | No | Additional notes or specific topics requested by the prospect. |
