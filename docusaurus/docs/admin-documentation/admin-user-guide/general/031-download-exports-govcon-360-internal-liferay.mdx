The **Downloads / Exports** page provides a centralized location to access your exported data and downloaded files. You can reach this page from the top navigation bar.

## Managing downloads and exports

1. Locate the **Client List** dropdown field on the main panel.
2. Click **Search or select a client...** and choose the appropriate client from the list to view results.
