Manage collaboration inquiries and partnership requests using the General section form. Access this page by navigating to **Administration** and selecting **Collaboration Requests**.

![Collaboration Requests](/img/admin/023-collaboration-requests-govcon-360-internal-liferay-screenshot.png)

## Collaboration request form

Use the general form fields to capture and submit partnership details or user collaboration notes.

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| **First Name** | Text | No | The requester's first name. |
| **Last Name** | Text | No | The requester's last name. |
| **Company Name** | Text | No | The organization or company associated with the request. |
| **Email Address** | Text | No | Contact email address for the individual. |
| **Phone Number** | Text | No | Direct phone number for follow-up. |
| **Message** | Textarea | No | Detailed comments or collaboration notes (up to 1000 characters). |
