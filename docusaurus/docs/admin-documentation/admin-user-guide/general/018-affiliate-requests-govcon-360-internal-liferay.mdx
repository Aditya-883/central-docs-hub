description: "Manage and review affiliate program applications and requests from the Administration section."

Review and manage incoming affiliate program submissions through the Affiliate Requests page, accessible via **Administration → Affiliate Requests**.

![Affiliate Requests](/img/admin/018-affiliate-requests-govcon-360-internal-liferay-screenshot.png)

## Affiliate Requests table

The main panel lists all pending and processed affiliate applications. You can use the **Search** box to find specific entries or click the **Add Affiliate Request** button to manually create a new entry.

| Column | Description |
| :--- | :--- |
| **First Name** | The first name of the affiliate applicant. |
| **Last Name** | The last name of the affiliate applicant. |
| **Email Address** | The contact email address for the applicant. |
| **Company Name** | The organization associated with the request. |
| **Application Status** | The current status of the request (e.g., **Pending**). |
| **Create Date** | The timestamp indicating when the affiliate request was submitted. |
