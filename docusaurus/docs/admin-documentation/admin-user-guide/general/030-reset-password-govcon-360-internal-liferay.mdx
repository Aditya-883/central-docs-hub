Use the **Change Password** page to update your account credentials. Your new password must be different from previously used passwords and meet the security complexity requirements.

## Change your password

1. Enter your existing credentials in the **Current Password** field.
2. Enter your new secure password in the **New Password** field.
3. Re-enter the exact same password in the **Reenter Password** field to confirm.
4. Verify that your new password satisfies all on-screen security indicators:
   - Must be at least 8 characters
   - Must contain an upper case letter
   - Must contain a lower case letter
   - Must contain a number
   - Must contain a special character
5. Click **Change Password** to save your new credentials.
