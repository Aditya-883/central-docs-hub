The Demo Requests page lets administrators track, filter, and manage incoming product demonstration requests. Access this page via **Administration** to view all pending and processed requests submitted by users.

## Demo Requests table

The main panel displays a list of all demo requests in a table format. You can click column headers like **First Name**, **Last Name**, **Email Address**, **Demo Date**, **Company Name**, or **Application Status** to sort the entries.

| Column | Description |
| :--- | :--- |
| **First Name** | The first name of the person requesting the demo. |
| **Last Name** | The last name of the person requesting the demo. |
| **Email Address** | The contact email address for the requester. |
| **Demo Date** | The scheduled date and time for the product demonstration. |
| **Company Name** | The organization or company associated with the request. |
| **Application Status** | The current status of the request (e.g., **Pending**). |

## Search and filters

Use the **Search** input field above the table to quickly find specific records by name, company, or email. Click the **+** (**Add Demo Request**) button to manually create a new demo request entry. Pagination controls at the bottom allow you to adjust the number of items displayed per page using the **20 Items** dropdown and navigate through large lists.
