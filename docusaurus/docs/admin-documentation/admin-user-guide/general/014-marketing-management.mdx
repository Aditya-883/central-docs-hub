Manage invoices, track payment status, and keep all billing information organized for your customers via **Commerce** → **Invoices and Payment**.

![Invoices and Payment](/img/admin/014-marketing-management-screenshot.png)

## Invoice metrics and actions

The top section of the page displays summary cards for financial tracking along with quick action controls.

| Element | Type / Description |
| :--- | :--- |
| **Outstanding** | Summary card showing total unpaid invoice amounts. |
| **Overdue** | Summary card showing the count of overdue invoices. |
| **Draft** | Summary card showing the count of draft invoices. |
| **Upload Invoice** | Button to upload and add new invoices to the system. |

## Search and filters

Use the search bar and dropdown filters to narrow down the invoice table by recipient, status, or payment method.

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **Search by recipient name or invoice numnber** | text | No | Filter records dynamically by typing a recipient name or invoice number. |
| **All Status** | select-one | No | Filter the invoice list by payment status (e.g., Paid, Outstanding, Overdue). |
| **All Payment Method** | select-one | No | Filter the invoice list by payment method (e.g., ACH). |

## Invoices table

The data table displays all tracked invoices with columns for **Name**, **Invoice Number**, **Invoice Date**, **Due date**, **Billing piriod**, **Amount**, **Payment Method**, and **Status**. Use the row action icons to view details or download individual records.
