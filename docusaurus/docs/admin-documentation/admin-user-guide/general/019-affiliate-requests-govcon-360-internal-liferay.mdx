Review and process incoming requests under **Administration → Affiliate Requests**. 

![Affiliate Requests](/img/admin/019-affiliate-requests-govcon-360-internal-liferay-screenshot.png)

## General information

The **General** section captures the contact and company details submitted by the affiliate applicant.

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **First Name** | Text | No | Applicant's first name. |
| **Last Name** | Text | No | Applicant's last name. |
| **Company Name** | Text | No | Name of the applicant's company. |
| **Email Address** | Text | No | Contact email address for the applicant. |

## Actions

The **Actions** section lets administrators control the status of the request.

| Control | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **Application Status** | Dropdown | Yes | Sets the current status of the affiliate request (e.g., **Pending**). |

## Metadata

Expand the **METADATA** section to view system tracking details and timestamps associated with the request record.
