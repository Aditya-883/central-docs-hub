The Collaboration Requests page allows administrators to review, search, and manage incoming partnership or user collaboration submissions. You can access this page by navigating to **Administration** and selecting **Collaboration Requests**.

![Collaboration Requests](/img/admin/022-collaboration-requests-govcon-360-internal-liferay-screenshot.png)

## Managing requests

The main panel displays a table of all submitted collaboration requests. Each entry includes user details, current status, and timestamps.

| Element | What it does |
| :--- | :--- |
| **Search** | Filter collaboration requests by entering keywords into the search bar. |
| **Add Collaboration Request** | Create a new collaboration request entry manually using the blue **+** button. |
| **First Name** / **Last Name** / **Email Address** | View the contact details of the requester. Click the column headers to sort ascending or descending. |
| **Application Status** | Displays the current review stage of the request (e.g., **Pending**). |
| **Create Date** | Shows the exact timestamp when the request was initiated. |
| **Actions** | Access additional row-level options via the three-dot menu icon. |

## Pagination and display settings

Use the controls at the bottom of the table to manage how many records appear per page. The dropdown menu allows you to adjust the view to show **20 Items** or more, and you can use the numbered pagination buttons to navigate between multiple pages of requests.
