description: "Manage invoices, track payment status, and organize billing information for B2B customers."

Manage invoices, track payment status, and keep all billing information organized in one place for B2B customers by navigating to **Commerce** → **Invoices and Payment**.

![page](/img/admin/012-invoices-and-payment-govcon-360-internal-liferay-screenshot.png)

## Invoice metrics and actions

The top section of the page provides a high-level summary of your financial metrics alongside primary actions.

| Element | Description |
| --- | --- |
| **Outstanding** | Displays the total monetary amount of outstanding invoices. |
| **Overdue** | Shows the count of overdue invoices needing attention. |
| **Draft** | Shows the count of invoices currently saved as drafts. |
| **Upload Invoice** | Opens the invoice upload workflow to add new billing documents to the system. |

## Search and filters

Use the search bar and filter dropdowns to quickly locate specific invoices in the table.

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| **Search by recipient name or invoice numnber** | Text | No | Enter keywords to filter the invoice list dynamically. |
| **All Status** | Select | No | Filter invoices by their current processing or payment status. |
| **All Payment Method** | Select | No | Filter invoices based on the method of payment (such as ACH). |

## Invoice table

The main data table displays all tracked billing records with details including **Name**, **Invoice Number**, **Invoice Date**, **Due date**, **Billing piriod**, **Amount**, **Payment Method**, and **Status**. Use the row actions to view or download individual invoices.
