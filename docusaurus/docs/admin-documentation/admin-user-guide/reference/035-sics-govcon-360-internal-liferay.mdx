Manage and search Standard Industrial Classification (SIC) codes, titles, and offices to categorize market intelligence and business data. Access this view by navigating through your application menu to reach the **SIC** reference page.

![Standard Industrial Classification (SIC)](/img/admin/035-sics-govcon-360-internal-liferay-screenshot.png)

## Search and Filter SIC Data

Use the filter and search controls above the data table to quickly locate specific industry classifications.

1. Select a matching rule from the dropdown menu (such as **Contains**, **Starts with**, **Ends with**, or **Exact match**).
2. Enter your search criteria in the **Type SIC Code, Title, Office** field.
3. Click **Apply** to filter the table results.
4. Optionally, click **Export** to download the current SIC data set.

| Element | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **Type SIC Code, Title, Office** | Text | No | Enter keywords, numbers, or office names to filter the table. |
| **Contains** | Dropdown | No | Specifies the matching criteria for your search query. |
| **Apply** | Button | No | Executes the search query against the table. |
| **Export** | Button | No | Exports the current view or filtered results. |

## Data Table Navigation

The SIC table displays system entries across multiple pages. Use the controls below the table to adjust your view:

- **Entries Per Page**: Select how many rows to display per page (default is **20**).
- **Jump To**: Enter a specific page number and click **Go** to skip directly to that page.
- **Pagination controls**: Use the arrow buttons or page numbers to navigate sequentially through the results.
- **Column sorting**: Click on **Code**, **Office**, or **Industry Title** column headers to sort the table data in ascending or descending order.
