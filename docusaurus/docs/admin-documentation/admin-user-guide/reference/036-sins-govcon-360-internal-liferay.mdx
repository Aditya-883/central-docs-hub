The Special Item Number (SIN) page allows you to view, search, and sort unique codes used by the GSA to categorize products and services authorized under a GSA Schedule contract. You can reach this page through the main application navigation.

![Special Item Number (SIN)](/img/admin/036-sins-govcon-360-internal-liferay-screenshot.png)

## SIN table and search

The main panel displays a paginated list of all available SIN records across your contract data. Each entry includes its category, subcategory, code, title, and description.

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **Search Category** | Text | No | Filter the table by **Category** values. |
| **Search Sub Category** | Text | No | Filter the table by **Sub Category** values. |
| **Search SIN** | Text | No | Filter the table by the specific numeric **SIN** code. |
| **Search SIN Title** | Text | No | Filter the table by **SIN Title**. |
| **Search SIN Description** | Text | No | Filter the table by keywords within the **SIN Description**. |

## Sorting and pagination

You can organize and navigate the table data using the built-in controls:

1. Click any column header (**Category**, **Sub Category**, **SIN**, **SIN Title**, or **SIN Description**) to sort the entries in ascending or descending order.
2. Use the pagination controls at the bottom or top-right of the table to jump between pages and view additional entries.
