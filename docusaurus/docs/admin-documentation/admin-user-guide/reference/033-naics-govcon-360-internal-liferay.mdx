Explore and search the North American Industry Classification System (NAICS) directory to categorize industries and filter codes by specific terms. You can reach this page via **Administration** or related reference sections in the top navigation.

![North American Industry Classification System (NAICS)](/img/admin/033-naics-govcon-360-internal-liferay-screenshot.png)

## Search and filter NAICS codes

Use the search bar and filter criteria to locate specific NAICS codes, titles, or descriptions.

1. Select your matching criteria from the operator dropdown (such as **Contains**, **Starts with**, **Ends with**, or **Exact match**).
2. Enter your search terms into the **Type NAICs Code, Title, Description** field.
3. Click **Apply** to run the query against the directory table.
4. Click **Export** if you need to download the filtered results.

## Table navigation

The NAICS directory displays results in a paginated data table. 

| Element | Description |
| :--- | :--- |
| **Entries Per Page** | Select how many rows appear per page using the dropdown (default is 20 entries). |
| **Jump To** | Enter a specific page number and click **Go** to navigate directly to that section. |
| Pagination Controls | Use the arrow buttons or page numbers to step through the result set. |
| **NAICS Code** / **NAICS Description** | Click the column headers to sort the table data in ascending or descending order. |
