The **Product and Service Code (PSC)** page allows you to browse, filter, and export federal Product and Service Codes used across government contracting. You can reach this page through the main navigation by selecting **Data Management** and clicking on **PSCs**.

![Product and Service Code (PSC)](/img/admin/034-pscs-govcon-360-internal-liferay-screenshot.png)

## PSC table and filtering

The main data table displays all available Product and Service Codes categorized by level and name. You can use the search boxes beneath each column header to filter the results:

| Element | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **Search PSC Code** | Text | No | Filter entries by specific PSC code. |
| **Search Level1 category Name** | Text | No | Filter entries by Level 1 category name. |
| **Search Level2 Category Name** | Text | No | Filter entries by Level 2 category name. |
| **Search PSC Name** | Text | No | Filter entries by descriptive PSC name. |

## Table controls and export

Use the pagination and action controls above and below the table to manage your view:

1. Adjust the **Entries Per Page** dropdown to show more or fewer rows per screen.
2. Type a page number into the **Jump To** box and click **Go** to navigate directly to a specific page.
3. Click the **Export** button in the upper right to export the current PSC dataset.
4. Click column headers such as **PSC Code**, **Level1 category Name**, **Level2 Category Name**, or **PSC Name** to sort the table data ascending or descending.
