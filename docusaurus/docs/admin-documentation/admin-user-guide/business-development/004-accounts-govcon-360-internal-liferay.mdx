Manage and update account details within the **Accounts** module. Navigate to **Accounts → Business Overview** to view and edit core profile parameters.

![page](/img/admin/004-accounts-govcon-360-internal-liferay-screenshot.png)

## Business Overview

The **Business Overview** form lets you capture key organizational attributes. Use the progress bar at the top to jump between **General Information**, **Point of Contact**, **Business Overview**, and **Company Details**.

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **Industry** | Text / Dropdown | Yes | Select or start typing an industry classification. |
| **Capabilities** | Text / Tag Input | Yes | Enter core business capabilities and offerings. |
| **Account Representative** | Text / Tag Input | No | Assign an internal account representative. |
| **Customer Success** | Text / Tag Input | No | Assign a customer success manager. |

## Navigation and Controls

Use the navigation buttons at the bottom of the form to move through the setup wizard:

1. Click **Previous** to return to the previous section.
2. Click **Next** to advance to the next step of the account creation or editing process.
