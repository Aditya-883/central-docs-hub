Manage your business relationships, client portfolios, and organization lists via **Accounts → Accounts**. 

## Accounts management

The accounts workspace provides tools to sort, filter, and add new client organizations. Use the sub-navigation tabs to toggle between business client types.

| Element | Description |
| --- | --- |
| **B2B** | Filters the account list to show business-to-business clients. |
| **B2C** | Filters the account list to show business-to-consumer clients. |
| **Add New Client** | Opens the creation form to set up a new client account. |

1. Navigate to **Accounts** from the main navigation bar.
2. Select either the **B2B** or **B2C** tab to view the appropriate client base.
3. Click **Add New Client** to input a new record into the system.
