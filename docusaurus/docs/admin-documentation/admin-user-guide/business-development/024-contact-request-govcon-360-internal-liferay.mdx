Manage incoming contact requests and review submission details by navigating to **Administration** and selecting the **Contact Request** view.

![Contact Request](/img/admin/024-contact-request-govcon-360-internal-liferay-screenshot.png)

## Header elements

The header area provides quick access to system tools, notifications, and user profile settings. You can switch between primary modules such as **Accounts**, **Customer Content**, **Data Management**, **Commerce**, **Marketing Management**, and **Administration**.

## Contact requests table

The main panel lists all submitted contact requests in a tabular format. You can sort columns by clicking on the respective column header.

| Column | Description |
| :--- | :--- |
| **First Name** | The first name of the contact. |
| **Last Name** | The last name of the contact. |
| **Email Address** | The email address provided in the request. |
| **Company Name** | The associated company name, if applicable. |
| **Application Status** | The current processing status of the request (e.g., **Pending**). |
| **Create Date** | The exact timestamp when the contact request was created. |

## Searching and filtering records

Use the **Search** input field above the table to quickly find specific contact requests by typing keywords, names, or company details. Click the **+** (Add Contact Request) button to manually record a new inquiry.

Use the pagination controls at the bottom of the table to adjust how many items display per page (defaulting to **20 Items**) and navigate between pages of records.
