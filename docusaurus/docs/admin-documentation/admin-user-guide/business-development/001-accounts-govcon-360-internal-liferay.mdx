The Accounts page allows you to view, manage, and create client accounts across your organization. Access this page from the main navigation by selecting **Accounts**.

![page](/img/admin/001-accounts-govcon-360-internal-liferay-screenshot.png)

## Client categories

Use the segment buttons directly below the main navigation bar to filter your account list by business model:

| Button | What it does |
| :--- | :--- |
| **B2B** | Displays business-to-business client accounts and enterprise partners. |
| **B2C** | Displays business-to-consumer client accounts. |

## Adding new clients

To add a new client to your portfolio:

1. Click **Add New Client** in the top-right corner of the data table area.
2. Complete the required client details in the onboarding workflow.

## Accounts table

The accounts table lists all registered client profiles, displaying key metadata across columns such as **Customer Name**, **Account Executive**, **Customer Success**, **Customer POC**, **UEI**, and **Cage Code**. 

You can perform inline management actions for any listed entry using the icons in the **Actions** column:
* **Edit**: Modify existing account configurations and profile metadata.
* **Delete**: Remove the client account from the system.
* **Assign/Unassign**: Adjust user or team ownership mappings.
