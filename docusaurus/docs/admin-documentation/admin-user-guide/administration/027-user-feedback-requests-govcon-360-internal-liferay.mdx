Review and submit user feedback requests, support inquiries, and application status details through the **User Feedback Requests** page. Navigate to this page via **Administration** to view and fill out user feedback form details.

![User Feedback Requests](/img/admin/027-user-feedback-requests-govcon-360-internal-liferay-screenshot.png)

## User feedback details

The main panel contains a **Details** section with user-submitted feedback criteria and contact fields.

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **First Name** | Text | No | The submitter's first name. |
| **Last Name** | Text | No | The submitter's last name. |
| **Email Address** | Text | No | Contact email address. |
| **Company Name** | Text | No | Organization or company name. |
| **Message** | Textarea | No | Details or comments provided in the feedback request. |
| **Phone Number** | Text | No | Contact telephone number. |
| **Application Status** | Select | Yes | Tracks the review status (default: **Pending**). |

## Managing feedback entries

1. Navigate to the **Administration** module to open the feedback request form.
2. Complete the required contact and message fields under **DETAILS**.
3. Set the **Application Status** dropdown as needed.
4. Click **Save** to record the entry or **Cancel** to discard changes.
