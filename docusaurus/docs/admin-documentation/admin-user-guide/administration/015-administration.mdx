description: "Manage invoices, track payment status, and organize billing information."

Manage invoices, track payment status, and keep all billing information organized in one place for B2B clients. Reach this page by navigating through **Commerce** or the **Administration** module dropdown menus.

![Invoices and Payment](/img/admin/015-administration-screenshot.png)

## Summary Cards

At the top of the page, three summary cards display key billing metrics at a glance:
- **Outstanding**: Shows the total monetary amount of pending invoices.
- **Overdue**: Shows the count of past-due invoices.
- **Draft**: Shows the count of invoices currently saved as drafts.

## Invoices and Payment Table

Use the search bar and filter dropdowns to locate specific records, or click **Upload Invoice** to add a new billing document.

| Element | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **Search by recipient name or invoice numnber** | text | No | Enter keywords to filter the list by recipient or invoice number. |
| **All Status** | select-one | No | Filter records by their payment status. |
| **All Payment Method** | select-one | No | Filter records by the method of payment. |
| **Upload Invoice** | button | No | Opens the upload workflow to add a new invoice. |
