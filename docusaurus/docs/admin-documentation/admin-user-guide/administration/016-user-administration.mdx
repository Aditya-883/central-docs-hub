Manage invoices, track payment status, and keep all billing information organized in one place for B2B customers by navigating to **Commerce → Administration → Invoices and Payment**.

![page](/img/admin/016-user-administration-screenshot.png)

## Summary cards

The top section of the page provides quick numerical summaries for your billing pipeline.

| Card | Description |
| :--- | :--- |
| **Outstanding** | Displays the total monetary amount of unpaid or pending invoices (`$0` when fully settled). |
| **Draft** | Displays the count of invoices currently saved in draft status (`0` when none exist). |

## Invoices and payment table

Use the search bar and filter dropdowns to locate specific records, or click **Upload Invoice** to add new billing documentation.

| Element | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| **Search by recipient name or invoice numnber** | Text input | No | Filter records dynamically by typing a recipient name or invoice number. |
| **All Status** | Dropdown | No | Filter records by payment or invoice status. |
| **All Payment Method** | Dropdown | No | Filter records by the selected payment method (e.g., ACH). |
| **Upload Invoice** | Button | Yes | Opens the modal or form to upload and register a new invoice. |
