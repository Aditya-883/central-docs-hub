Manage individual user profiles, account details, seat assignments, and administrative roles within your organization by navigating to **Administration** → **User Management**.

![page](/img/admin/029-user-management-govcon-360-internal-liferay-screenshot.png)

## User profile details

The upper section displays the selected user's primary name, avatar, system roles, and status indicators. 

| Element | What it does |
| :--- | :--- |
| **Go Back** | Returns you to the previous user list view. |
| **Edit name** | Allows you to modify the displayed name for the user. |

:::warning
If a user is designated as the sole remaining administrator, administrative access cannot be removed and the user cannot be deactivated until a secondary admin is assigned.
:::

## Account details and billing

The lower portion of the page breaks down personal identification fields and subscription licensing information.

- **Account details**: Displays the user's **First name**, **Last name**, **Email**, and assigned system **Role** (**General user**, **Admin**).
- **Seat and billing**: Outlines license utilization, showing metrics such as committed seats, currently used seats, and contract terms.
