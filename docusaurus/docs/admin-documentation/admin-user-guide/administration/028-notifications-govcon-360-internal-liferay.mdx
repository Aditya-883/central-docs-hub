View and manage system alerts and messages by accessing the **Notifications** page from the top navigation bar.

![Notifications](/img/admin/028-notifications-govcon-360-internal-liferay-screenshot.png)

## Notification tabs

Filter your alerts using the tabs located beneath the **Notifications** header.

| Tab | Description |
| :--- | :--- |
| **All** | Displays all system notifications regardless of their read status. |
| **Unread** | Displays only unread notifications, with the current count shown in parentheses. |
