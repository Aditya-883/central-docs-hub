View and manage submitted user feedback requests by navigating to **Administration → User Feedback Requests**.

![User Feedback Requests](/img/admin/026-user-feedback-requests-govcon-360-internal-liferay-screenshot.png)

## User feedback requests table

The main panel displays all submitted feedback items in a tabular format. You can sort columns by clicking the sort arrows next to the column headers.

| Column Header | Description |
| :--- | :--- |
| **ID** | Unique identifier for the feedback request. Click the ID to view details. |
| **First Name** | Submitting user's first name. |
| **Last Name** | Submitting user's last name. |
| **Email Address** | Contact email of the user. |
| **Company Name** | Organization associated with the submission. |
| **Phone Number** | Contact phone number, if provided. |
| **Message** | The content or notes of the user feedback. |

## Managing feedback entries

1. Use the **Search** field above the table to quickly find specific feedback requests by keyword.
2. Click the **Add User Feedback Request** button to manually create a new feedback entry.
3. Adjust the pagination dropdown set to **20 Items** to control how many rows display per page, and use the pagination controls at the bottom right to navigate through pages.
