## Overview

The Reset Password page allows you to securely update your account password. Your new password must be different from previously used passwords and meet specific complexity requirements. While navigating your account settings, you can also review recent [Notifications](./notifications.mdx), manage your [User Profile](./users.mdx), or return to the main [Dashboard](./dashboard.mdx).

## Page Features

- **Change Password**: The core section for updating account credentials. It includes validation requirements indicating that your new password must:
  - Be at least 8 characters long
  - Contain an upper case letter
  - Contain a lower case letter
  - Contain a number
  - Contain a special character
- **Action Buttons**: Includes buttons to **Cancel** the operation or submit the changes via **Change Password**.

## Step-by-Step Workflow

1. Enter your current password in the **Current Password** field.
2. Enter your new password in the **New Password** field, ensuring it meets all complexity guidelines.
3. Re-enter your new password in the **Reenter Password** field to confirm.
4. Click **Change Password** to save your new credentials, or click **Cancel** to abort the process.

## Form Fields Reference

| Field Label | Type | Required | Validation / Description |
|---|---|---|---|
| Current Password | password | Yes | Enter your existing account password. |
| New Password | password | Yes | Must be at least 8 characters, contain an upper case letter, a lower case letter, a number, and a special character. Must be different from previously used passwords. |
| Reenter Password | password | Yes | Must match the new password exactly. |

:::tip
Always ensure your new password satisfies all five complexity requirements before attempting to submit the form.
:::
