## Overview

The Reset Password page allows users to update their account credentials safely. Your new password must be different from previously used passwords. Once updated, you can return to navigating your [Dashboard](./dashboard.mdx), checking your [User Profile](./users.mdx), or reviewing system [View All](./notifications.mdx) notifications.

## Screen Reference

![Page Screenshot](/img/client/04-reset-password-screenshot.png)

## Page Features

- **Change Password**: The primary section containing fields required to update your security credentials.
- **Password Requirements**: Guidelines to ensure account security, including minimum length and character complexity rules.

## Step-by-Step Workflow

1. Navigate to the Reset Password page.
2. Enter your current password in the **Current Password** field.
3. Enter your new password in the **New Password** field, ensuring it meets all complexity requirements.
4. Re-enter your new password in the **Reenter Password** field to confirm.
5. Click **Change Password** to save your new credentials, or click **Cancel** to discard changes.

## Form Fields Reference

| Field Label | Type | Required | Validation / Description |
|---|---|---|---|
| Current Password | password | Yes | Enter your existing account password. |
| New Password | password | Yes | Must be at least 8 characters, contain an upper case letter, a lower case letter, a number, and a special character. Must be different from previously used passwords. |
| Reenter Password | password | Yes | Must match the new password exactly. |

## Additional Information

The page header provides quick access to top-level system navigation, including your **Dashboard** and notification alerts. 

:::tip
Ensure your new password adheres strictly to all listed complexity requirements and is unique from previous credentials to maintain account security.
:::
