## Overview

The User Management page allows administrators and account owners to oversee user access, view current user counts, and manage account settings for Asponte Technology Inc. You can review active users, navigate to your **[Dashboard](./dashboard.mdx)**, or review system activity such as **[View All](./notifications.mdx)** notifications.

## Page Features

- **User Metrics**: Displays the total count of registered users (indicated as 7) associated with the organization.
- **Account Settings**: Access security features such as **[Change Password](./reset-password.mdx)** to update your authentication credentials.

:::tip
Regularly review your user list and manage permissions to ensure proper access control across your organization.
:::
