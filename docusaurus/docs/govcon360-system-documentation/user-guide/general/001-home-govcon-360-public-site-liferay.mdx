The GovCon360 public home page provides an overview of government contracting software solutions, core features, pricing, and resources to help small businesses navigate the federal marketplace. You can access this page by navigating to the public-facing GovCon360 website.

![page](/img/public/001-home-govcon-360-public-site-liferay-screenshot.png)

## Header elements and navigation

The top header bar remains consistent across the public site, allowing you to explore platform offerings and access your account.

| Element | Description |
| :--- | :--- |
| **GovCon360** logo | Returns you to the home page from anywhere on the public site. |
| **Home** | Navigates back to the main landing page. |
| **Solutions For** | Displays drop-down options tailored to specific user types or business needs. |
| **Features** | Outlines core software capabilities and tools. |
| **Pricing** | Displays subscription plans and package tiers. |
| **Resources** | Provides access to guides, documentation, and helpful materials. |
| **About** | Shares company background and mission information. |
| **Explore** | Highlights additional platform insights and content. |
| **Login** | Takes you to the sign-in page to access your account. |

## Main landing and core features

The central hero banner highlights the core mission of simplifying government contracting, featuring a **Schedule a Demo** button to request a walkthrough of the platform. Below the hero section, the **CORE FEATURES** section introduces tools designed to help your team find opportunities, manage bids, and win federal work.

## Cookie and accessibility preferences

At the bottom of the page, a cookie notice banner allows you to manage your site preferences. You can click **Customize** to adjust your preferences, **Reject all** to decline non-essential cookies, or **Accept all** to enable all cookies. Additionally, you can manage your preferences using the **Cookie Settings** and **Accessibility Settings** buttons.
