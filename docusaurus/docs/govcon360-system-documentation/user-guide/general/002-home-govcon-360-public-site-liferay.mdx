The GovCon360 public home page serves as the main entry point to learn about government contracting software, view pricing, explore features, and access your account. You can reach the site by navigating to the public URL.

![page](/img/public/002-home-govcon-360-public-site-liferay-screenshot.png)

## Header navigation

The top header provides quick access to main public sections, informational drop-down menus, and authentication options.

| Element | Description |
| :--- | :--- |
| **Home** | Returns you to the main landing page. |
| **Solutions For** | Opens a menu of targeted solutions. |
| **Features** | Displays available software features and capabilities. |
| **Pricing** | Outlines subscription tiers and plans. |
| **Resources** | Provides access to educational materials and guides. |
| **About** | Shares company background and information. |
| **Explore** | Offers additional platform insights. |
| **Login** | Navigates to the sign-in portal. |

## Main landing content

The hero section highlights the primary value proposition of the platform, offering a **Schedule a Demo** button to request a personalized walkthrough of the software. Below the hero section, the page outlines core features designed to help small businesses find and win government contracts.

## Cookie and accessibility preferences

A banner at the bottom of the screen allows you to manage your cookie preferences and site interactions.

| Control | Description |
| :--- | :--- |
| **Customize** | Opens preferences to select specific cookie categories. |
| **Reject all** | Declines optional cookies and analytics tracking. |
| **Accept all** | Accepts all cookies for the best possible site experience. |
| **Cookie Settings** | Accesses detailed cookie configuration options. |
| **Accessibility Settings** | Adjusts display and interaction preferences for accessibility. |
