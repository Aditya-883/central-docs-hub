Explore government contract leads and focus on winnable work using the GovCon360 public site tools. You can reach this page via the main navigation under **Features → Lead Prospector**.

![Government Contract Lead Prospector](/img/public/008-lead-prospector-govcon-360-public-site-liferay-screenshot.png)

## Header elements

The top navigation bar provides public-facing options and access points to the platform:

| Element | What it does |
| :--- | :--- |
| **Home** | Navigates back to the main landing page. |
| **Solutions For** | Displays available solutions grouped by business type. |
| **Features** | Expands a menu to view platform capabilities such as Lead Prospector. |
| **Pricing** | Opens subscription and tier information. |
| **Resources** | Provides access to educational materials, blogs, and guides. |
| **About** | Shares company information and background. |
| **Explore** | Opens additional product exploration tools. |
| **Schedule a Demo** | Requests a personalized walkthrough of the platform. |
| **Login** | Accesses the sign-in screen for your account. |

## Lead Prospector and Market Intel

The page provides simple, configurable searches matching what you sell with the agencies that are buying. 

- **Federal Find & Nurture**: Automatically displays contracts matching your unique capabilities by setting up preset filters such as **Keywords**, **NAICS**, **PSC**, **Agency**, **contract value**, and **place of performance**.
- **Cookie Consent Banner**: Manage your tracking preferences using **Customize**, **Reject all**, or **Accept all** buttons at the bottom of the screen.
