Explore government contracting tools, resources, and pricing information tailored for small businesses via the public site menu.

![page](/img/public/004-small-businesses-govcon-360-public-site-liferay-screenshot.png)

## Header elements

The header navigation allows you to access core informational pages, platform features, and user authentication.

| Element | What it does |
| :--- | :--- |
| **GovCon360 Logo** | Returns you to the main home page. |
| **Home** | Navigates to the primary landing page. |
| **Solutions For** | Displays industry and business size solutions dropdown. |
| **Features** | Opens the features and platform capabilities menu. |
| **Pricing** | Views available subscription and package plans. |
| **Resources** | Accesses guides, articles, and documentation. |
| **About** | Learn more about the company and team. |
| **Explore** | Discover additional tools and market intelligence. |
| **Schedule a Demo** | Requests a personalized walkthrough of the platform. |
| **Login** | Accesses your account sign-in page. |

## Cookie and privacy preferences

When visiting the site, use the bottom cookie consent banner to manage your data preferences.

| Button | What it does |
| :--- | :--- |
| **Customize** | Opens granular consent options for site cookies and tracking. |
| **Reject all** | Declines all non-essential cookies. |
| **Accept all** | Approves all cookies to deliver personalized content and analyze site traffic. |
