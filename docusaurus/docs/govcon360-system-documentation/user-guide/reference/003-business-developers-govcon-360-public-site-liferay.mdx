GovCon360 provides specialized tools and market intelligence designed for business developers to track opportunities, analyze agency trends, and manage federal pipelines. Access this public overview page directly from the main website navigation by selecting **Solutions For** and choosing the business developer option.

![page](/img/public/003-business-developers-govcon-360-public-site-liferay-screenshot.png)

## Header elements

The public header provides global navigation across the platform, allowing you to explore site sections or access your account.

| Element | What it does |
| :--- | :--- |
| **Home** | Returns you to the main landing page. |
| **Solutions For** | Opens a dropdown menu of tailored solutions for different contracting roles. |
| **Features** | Displays core platform capabilities and modules. |
| **Pricing** | Outlines available subscription tiers and packages. |
| **Resources** | Accesses guides, whitepapers, and documentation. |
| **About** | Provides company background and mission details. |
| **Explore** | Navigates to additional exploratory content and tools. |
| **Schedule a Demo** | Opens a request form to book a personalized walkthrough of the platform. |
| **Login** | Directs you to the sign-in page to access your secure workspace. |

## Cookie and privacy preferences

When visiting the site, a privacy banner appears at the bottom of the page to manage tracking preferences.

| Button | What it does |
| :--- | :--- |
| **Customize** | Opens granular preference settings for cookies and data collection. |
| **Reject all** | Declines all non-essential tracking cookies. |
| **Accept all** | Enables all cookies to ensure optimal site functionality and personalization. |
